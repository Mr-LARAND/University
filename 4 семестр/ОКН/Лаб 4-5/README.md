### 5. Ответы на контрольные вопросы (для защиты)

1. **Что такое семантическая сеть?**
   Это информационная модель предметной области в виде ориентированного графа, где вершины — это объекты (понятия, события), а дуги — отношения между ними.
2. **Что такое транзитивность отношений?**
   Свойство отношения, при котором из связи $A$ с $B$ и $B$ с $C$ следует связь $A$ с $C$. Пример транзитивного: отношение *is_a* (Драмтеатр это Театр, Театр это Организация $\rightarrow$ Драмтеатр это Организация). Нетранзитивное: "любит" (А любит Б, Б любит В $\neq$ А любит В).
3. **Механизм наследования и переопределение:**
   Наследование позволяет нижележащим узлам (подклассам и экземплярам) автоматически приобретать свойства вышестоящих узлов. Переопределение — это когда свойство задается заново на более низком уровне с другим значением (исключение), отменяя для этого узла унаследованное значение. (Пример: птицы летают, но пингвин (подкласс) не летает).
4. **Основные типы отношений:**
   * Классифицирующие: *is_a* (класс-подкласс) и *instance_of* (класс-экземпляр).
   * Меронимические: *part_of* (часть-целое, например, "двигатель - часть машины").
   * Атрибутивные: свойства объекта ("цвет", "размер").
5. **Класс и экземпляр:**
   Класс описывает абстрактное множество объектов со схожими свойствами (например, класс `Актер`). Экземпляр — это конкретный, физический объект или представитель этого множества (например, актер `Петров`).
6. **Достоинства и недостатки:**
   * *Достоинства:* наглядность (близость к человеческому восприятию), удобство работы со структурными связями.
   * *Недостатки:* сложность поиска в больших сетях, отсутствие единой стандартизированной системы вывода (в отличие от строгой логики).
7. **XAI (Объяснимый ИИ):**
   Это направление ИИ, направленное на создание систем, чьи решения понятны человеку. Семантические сети отлично подходят для XAI, так как связи логичны и позволяют проследить весь путь вывода (почему система приняла такое решение).
8. **Предикаты для таксономии:**
   В программе использованы предикаты `is_a` (для связи классов) и `instance_of` (для связи экземпляров с их классом).
9. **`class_property` vs `instance_property`:**
   `class_property` задает свойства, общие для всех представителей класса (например, все актеры носят костюмы). `instance_property` задает индивидуальные свойства конкретного объекта, которые не относятся ко всем (возраст конкретного человека).
10. **Механизм подъёма:**
    В предикате `get_class_property` используется рекурсия. Если свойство не найдено у текущего класса, происходит вызов для `SuperClass`, который находится через факт `is_a(Class, SuperClass)`.
11. **Отсечения (`!`) в коде:**
    Они нужны для реализации переопределения (исключений). Отсечение запрещает Prolog'у искать альтернативные варианты с помощью поиска с возвратом (backtracking), если свойство уже было найдено на более специфичном уровне. Без `!` система выдала бы оба значения: и переопределенное (искусство), и унаследованное (прибыль).
12. **Современные технологии:**
    * **Knowledge Graphs (Графы знаний)** — используются поисковыми системами (например, Google) для выдачи точных ответов на запросы о связанных сущностях.
    * **Semantic Web (OWL / RDF)** — стандарты W3C для связи и структурирования данных в интернете, чтобы машины могли "понимать" смысл информации.

Если остались вопросы или нужно как-то поменять свойства — дай знать! Удачи на защите!
