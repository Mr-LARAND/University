# Библиотека матричных вычислений

## Описание проекта

Данный проект представляет собой реализацию статической и динамической библиотеки на языке C для работы с матрицами. Основная задача библиотеки нахождение обратной матрицы.

| Файл | Назначение |
|---|---|
| `matrix.h` | Заголовочный файл с объявлениями сигнатур функций. |
| `matrix.c` | Исходный код реализации математических алгоритмов. |
| `main.c` | Тестовая программа для демонстрации. |
| `Makefile` | Сценарий автоматической сборки статической/динамической библиотек и исполняемого файла. |

---

## Реализованные функции 

Библиотека предоставляет следующий интерфейс для работы:

| Имя функции | Описание | Возвращаемое значение |
|---|---|---|
| `allocate_matrix` | Динамическое выделение памяти под двумерный массив заданного размера | Указатель `double**` (или `NULL` при ошибке) |
| `free_matrix` | Корректное освобождение памяти, занятой матрицей | `void` |
| `gauss_jordan_inverse`| Нахождение обратной матрицы методом Жордана-Гаусса | `true` или `false` (матрица вырождена) |
| `gauss_inverse` | Нахождение обратной матрицы классическим методом Гаусса | `true` или `false` (матрица вырождена) |

---

## Сборка и запуск

Управление сборкой осуществляется с помощью утилиты `make`. Доступны следующие цели:

| Команда терминала | Выполняемое действие | Итоговый результат |
|---|---|---|
| `make` | Компиляция всех компонентов проекта | Создаются файлы: `matrix.o`, `libmatrix.a`, `libmatrix.so` и программа `test_matrix` |
| `make run` | Сборка (если требуется) и запуск тестов | Вывод исходной и обратных матриц в консоль |
| `make clean` | Очистка рабочей директории | Удаление всех скомпилированных `.o`, `.a`, `.so` и исполняемых файлов |3
